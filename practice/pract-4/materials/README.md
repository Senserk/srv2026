# Практическое занятие 4. Работа с данными TraceShop

За 70 минут группа вместе с преподавателем превращает журнал событий в набор
объектов для аналитической модели и сравнивает корректную оценку с экспериментом,
содержащим утечку данных. `practice.ipynb` — шаблон: код в него переносится
по шагам из студенческой методички.

## Запуск

```bash
docker compose up -d --build
docker compose ps
```

Откройте `http://localhost:8888/lab/tree/practice.ipynb`. Заполняйте ячейки
с пометкой `ВАШ КОД` сверху вниз. Исходные CSV не изменяются; результаты
сохраняются в `output/`.

## Ход работы

| Время | Работа | Результат |
|---:|---|---|
| 8 минут | Профиль качества | семь измеримых нарушений |
| 10 минут | Очистка | чистый журнал и карантин |
| 15 минут | Объекты и признаки | пятиминутные окна по источнику |
| 10 минут | Аудит утечки | решение по семи полям |
| 17 минут | Два эксперимента | метрики и матрицы ошибок |
| 7 минут | Выпуск | CSV и паспорт набора |
| 3 минуты | Обсуждение | интерпретация результата |

Под ячейками ряда шагов находятся готовые контрольные ячейки
(`# Контрольная таблица`): их не нужно набирать, достаточно запустить и сверить
таблицу с экраном преподавателя.

Используемая модель фиксирована. Подбирать алгоритм и гиперпараметры не нужно:
цель занятия — оценить влияние подготовки данных.

## Проверка

В терминале JupyterLab выполните:

```bash
python3 verify/verify.py output
```

Успешная проверка заканчивается строкой `Результат принят.`

Остановка среды:

```bash
docker compose down
```
